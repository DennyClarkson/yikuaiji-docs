反馈前准备什么

  1. 写下设备型号、系统版本、应用版本或 TestFlight 构建号。
  2. 说明你做了什么、期待什么、实际发生什么；能用虚构数据重现时优先使用虚构数据。
  3. 仅附带已遮盖隐私的报错。不要发送 API Key、应用密码、邀请码、完整小票、账本数据库或身份证件。
  4. 涉及同步时，说明是否开启照片同步、是否为不同设备、报错发生在哪一步；不要把服务器登录信息发来。

测试期间也可以通过 TestFlight 提交反馈。我们不会要求你提供密码或完整财务数据来获取帮助。本邮箱不提供转账、投资或专业财税咨询。

数据控制与恢复

你依法保有自己数据的权益，自主决定保存、导出、删除及是否分享；其他人的合法权益不受影响。请妥善保管设备、服务凭据和原始照片，定期验证独立备份。JSON/CSV 不打包照片，同步也不是独立历史备份。

当前没有由开发者托管的官方账本或恢复服务，我们通常不持有你的本地数据和解密凭据，不能承诺恢复丢失的数据。数据风险及法定责任详见用户协议；“数据归用户”不等于排除开发者依法应承担的责任。

隐私请求请在邮件主题注明“一块记隐私请求”，说明你需要查阅、更正、删除或撤回的内容。仅核验处理请求所需的最少信息，按适用法律要求处理。有关独立服务商和其他成员持有的副本，会说明可行操作及能力边界。

目前处于测试和正式发布准备阶段，尚未正式上架。计划在中国大陆、中国香港通过 App Store 一次性付费下载；不是自动续费订阅，第三方存储和模型费用另计。最终地区、价格和包含功能以实际商店页面为准。本站不提供交易或付款链接。

协议和隐私说明仍为发布准备稿，公开阅读不代表已经完成备案、法律审查或 App Store 审核。退款及其他消费者权利按商店机制和适用法律办理，不因“买断”而一概排除。
