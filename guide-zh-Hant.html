1. 第一次使用：先不配雲服務

一塊記用來記錄旅行、家庭、伴侶或小團隊的支出。帳本就像一本獨立的記帳簿；記錄是一筆支出；草稿是尚未確認的記錄。基本記帳不需要註冊一塊記帳號，也不需要 WebDAV 或 API Key。

  1. 打開底部“帳本”，進入已有帳本，或點“新增帳本”。給帳本取一個能認出的名字，例如“週末旅行”。
  2. 選擇本位幣，即統計總額統一使用的幣種。例如平時看人民幣總額就選 CNY。不要為了臨時記錄一筆美元支出而換整本帳本的本位幣。
  3. 進入帳本，新增一筆虛構的“午餐 20 元”，檢查日期、幣種和分類，再點“確認儲存”。
  4. 到“統計”檢查結果。只有正式保存的記錄才計入統計；篩選條件和當前帳本也會影響結果。

成功標誌：帳本中看到記錄，重新打開應用後仍能找到。到這裏已經可以開始記帳；後面的共享與外部整理都是可選功能。

2. 帳本首頁、切換與封存

  1. 底部“帳本”是所有帳本的首頁，新建和進入帳本都在這裏完成。先進入你要使用的帳本，再打開設置或統計，它們會作用於當前帳本。
  2. 要整理不常用帳本，打開帳本卡片菜單，選擇封存。封存只在本機隱藏首頁入口，資料、附件和同步連接仍保留，也不會讓其他成員的帳本消失。
  3. 在帳本首頁右上角打開“已封存帳本”，找到目標後恢復。最後一個未封存帳本不能封存，以保留可用入口。

封存不是刪除，也不是停止同步。想停用共享，請到對應帳本的 WebDAV 頁面斷開連接。

3. 手動記帳、退出和草稿

  1. 進入帳本並新增記錄，填寫商户、金額、幣種、日期、分類及需要的備註。
  2. 暫時不想保存，可正常返回或下滑關閉編輯頁；已輸入的內容會自動保存為草稿。不要用強制結束應用代替正常退出，系統終止、存儲失敗或設備故障時最後的改動仍可能丟失。
  3. 回到帳本的草稿入口，繼續編輯。草稿不進入正式統計，也不作為正式帳目同步給其他設備。
  4. 核對後點擊“確認儲存”。編輯已有記錄時也請確認保存後再檢查結果。

成功標誌：草稿中能恢復輸入；確認保存後，正式記錄出現。重要憑證仍請獨立留存。

4. 拍照與匯入小票：識別不等於入帳

OCR 是“把照片裏的字讀出來”，不是替你核實消費。

  1. 新增記錄時選擇拍照或匯入圖片。首次使用相機/照片選擇時，按系統提示授權；拒絕後仍可手動記帳。以後可在系統設置中更改權限。
  2. 讓小票平整、光線充足，儘量包含商户、日期和合計，避免反光、模糊或截掉金額。圖片可能帶有拍攝元資料，分享前請自行清理不想暴露的信息。
  3. 等設備端識別後，逐項核對：合計是不是實付金額、日期是否正確、幣種有沒有選錯、退款或折扣是否誤讀。
  4. 如需外部模型輔助整理，先按 DeepSeek 章節配置，再主動選擇“使用外部 API 整理”。不同設備的端側能力不同，不能保證每台設備都有系統模型。
  5. 只有你點“確認儲存”才入帳。識別失敗時可繼續手填，不需要反覆上傳同一張照片。

5. 篩選、多選和統計

  1. 在“最近記錄”旁打開篩選，可設置單日/日期範圍、關鍵字及“付款人（記錄人）”。條件會同時生效，日期範圍包含起止兩天。
  2. 保持篩選，點選擇按鈕或長按記錄進入多選。“全選”及匯出只針對當前篩選可見的結果；改條件後請重新核對所選項。
  3. 統計頁可按日期和記錄人查看分類、商户、日/月趨勢；回收站記錄和草稿不計入。

注意：當前“付款人（記錄人）”主要依據記錄作者標記，並非經過身份核驗的實際付款人，也不是分帳、轉帳或債務證明。舊記錄可能顯示“未標記記錄人”。跨幣種總額使用保存時鎖定的本位幣金額。

6. WebDAV 是什麼，什麼時候需要它

WebDAV 是讓應用讀寫你指定的遠程資料夾的一種方式。你可以選支持 WebDAV 的存儲服務或自有伺服器；不是所有網盤都支持。只在一台設備記帳時可以完全跳過。

它和外部模型是兩回事：WebDAV 存儲並同步加密帳目/可選照片；外部模型幫助整理文字。兩者帳號、密碼和用途不同。

開始前準備四樣東西：服務商給出的 WebDAV HTTPS 地址、WebDAV 用户名、專用應用密碼，以及你在共享帳本里的名稱。服務本身可能收費；請自行閲讀其價格、私隱政策、保存地區和訪問權限。

請只與可信成員共享。加密不能阻止已經獲准訪問的成員複製、修改或刪除內容；當前沒有逐成員只讀權限、踢人或自動換鑰匙的功能。

7. WebDAV 準備：從服務商拿到正確資料

  1. 用瀏覽器登錄你選擇的服務商官方網站，查找“WebDAV”“第三方應用”“應用密碼”或“安全設置”。不同服務入口不同，找不到時查其官方幫助，先確認服務支持 WebDAV。
  2. 啓用 WebDAV（如果服務需要），按其指引創建專門給一塊記使用的應用密碼。應用密碼類似單獨配給應用的鑰匙；不要默認使用網頁登錄密碼，更不要填寫短信驗證碼。
  3. 複製其文件指定的 WebDAV HTTPS 地址。它不是網頁登錄頁，不是普通文件分享鏈接，也不是任意拼接的資料夾地址。
  4. 如服務支持，把權限限定到專用目錄，例如 YiKuaiJi。地址是否需要附加子目錄，以服務商説明為準；不確定時先在其官方客户端驗證。不要授予整個私人網盤權限再把憑據發給別人。
  5. 保留正確的用户名和應用密碼到你信任的密碼管理器中。不要發給開發者，也不要截圖到羣聊。

格式示例：https://dav.example.com/your-folder/ 。這是示例地址，不能直接使用；請替換為自己的真實地址。必須使用有效 HTTPS，不能通過關閉證書校驗來解決連接問題。

8. WebDAV 創建共享：第一台設備逐格填寫

  1. 在“帳本”進入要共享的帳本。打開“設定 → 連接同步方式”，確認頁面頂部帳本名稱正確，再選擇“建立共享”。
  2. “WebDAV HTTPS 網址”：粘貼服務商提供的完整地址，檢查有沒有空格、漏掉 https:// 或誤貼網頁鏈接。
  3. “WebDAV 帳號”：填寫服務商指定的用户名，有的使用郵箱，有的使用獨立用户名。
  4. “WebDAV 應用密碼”：粘貼剛創建的應用密碼。它不是一塊記邀請碼，也不是外部模型 API Key。
  5. “我的名稱”：填其他成員能認出的稱呼，例如“小林”；該名稱會作為共享記錄的成員信息，不必填真實姓名。
  6. 點擊“建立並預覽”。這一步會訪問伺服器驗證權限，必要時創建應用目錄，並讀取遠端狀態；看到預覽後，逐項檢查上傳/下載內容，再點擊“確認同步”。取消預覽不會撤銷已保存的連接，請按需要另行斷開。
  7. 頁面顯示“WebDAV 已連接”後，可選擇“儲存為 WebDAV 預設”並命名。以後新建帳本時可複用地址與憑據，但仍需單獨創建或加入共享。不要在公用設備保存預設。

成功標誌：無連接錯誤，完成確認同步後出現同步結果。僅顯示“已連接”還不等於另一台設備已拿到資料。

9. WebDAV 加入已有帳本：第二台設備

  1. 創建者在已連接頁面點“複製邀請碼”，僅通過可信私密渠道發給你。普通邀請碼含遠程帳本標識和解密鑰匙，不含 WebDAV 帳號或應用密碼；它不是 TestFlight 兑換碼，也不是商店購買憑證。
  2. 在第二台設備先創建空帳本，選擇與原帳本相同的本位幣。不要在有自己帳目的帳本上嘗試合併加入。
  3. 進入該空帳本，打開“設定 → 連接同步方式”，選擇“加入現有共享”。填寫能訪問同一遠端目錄的 HTTPS 地址、帳號、應用密碼，以及你自己的“我的名稱”。
  4. 粘貼完整“共享邀請碼”，點擊“加入並預覽”，核對下載項後確認同步。
  5. 兩台設備各新增一筆不含私隱的測試記錄，分別同步，再在另一端同步並核對。先確認文字往返成功，再開啓照片。

快速邀請是可選捷徑：創建者點“產生快速邀請（包含帳號密碼）”，設置 6 至 12 位數字口令；接收者點“匯入快速邀請（包含帳號密碼）”，粘貼文字或掃描二維碼並輸入口令，核對填入信息後再加入。數字口令應現場口頭另行告知，不要和邀請文本發在同一條消息裏。

快速邀請包含可解密的帳號密碼，數字口令的保護能力有限，不是一次性、可撤銷或會自動過期的鏈接。不公開發布，也不轉發給陌生人。服務允許時優先給成員發僅限專用目錄的獨立憑據。

10. WebDAV 同步確認、自動同步與照片

  1. 想每次先看清單，請到當前帳本的 WebDAV 頁面點“立即同步”，閲讀上傳、下載、刪除和照片項目後再確認。
  2. 帳本頁右上角的快捷同步檢查所有已連接帳本，無衝突時直接完成，並非每次都給完整清單；同一字段衝突時需選擇。圖標旋轉表示工作中，短暫變綠表示該次完成。
  3. 想自己掌控每次上傳，保持“設定 → 自動同步”的各項關閉，並使用上述預覽入口。開啓進入前台、新增記錄後或間隔同步，就是允許滿足該條件時執行同步；它們只在應用前台工作，不保證後台持續同步。
  4. 需要共享照片時，在當前帳本 WebDAV 頁開啓“同步收據照片”，閲讀彈窗再確認。每台需要傳/收照片的設備都應檢查自己的開關。當前帳本關聯的小票及貨品附件可能被同步，並不只針對之後新拍的圖片。
  5. 未開啓時只同步帳目；另一位成員沒有上傳照片，或遠端暫缺文件時，文字帳目仍能同步。看到缺圖提示不等於帳目丟了；讓持有原圖的成員開啓照片同步並補傳，再在你的設備重試。

關閉照片同步只停止後續傳輸，不刪除已上傳照片。同步也不是獨立備份：誤刪或錯誤修改可能傳到所有設備。

11. WebDAV 連不上：按報錯排查

  1. 401/403：先在服務商處確認帳號、應用密碼和專用目錄權限；網頁登錄成功不代表 WebDAV 密碼或權限正確。密碼失效時重建專用密碼，再修改連接。
  2. 404：連接時出現通常要核對完整地址及目錄；同步完成後的“照片未上傳/已跳過”提示只針對缺失附件，不要因此刪除帳本。
  3. 405/409：核對服務是否允許應用創建目錄，以及路徑是否是可用的 WebDAV 資料夾，不要反覆新建共享或清空遠端嘗試修復。
  4. 429/配額不足：停止反覆點擊，等待限流恢復或到服務商檢查容量、請求額度和文件大小限制。
  5. 超時/證書錯誤：檢查網絡、設備時間、伺服器狀態及 HTTPS 證書；不要關閉安全校驗。解密失敗時核對是否用了同一帳本的邀請碼，不要用強制上傳來“試試看”。

“強制上傳本機資料”是高風險修復工具，可能刪除遠端獨有記錄。新手不要用它排查網絡問題。先匯出並保留原始附件，與所有成員確認哪一端完整，再考慮該操作。

12. DeepSeek 示例：認識 API Key 與費用

外部模型是可選的文字整理助手，不是記帳必需品。DeepSeek 只是配置示例，不表示一塊記與其有合作、擔保或綁定；也可以使用你信任的兼容服務。

API Key 是讓應用訪問你模型帳號的密鑰，類似應用專用密碼。網頁登錄帳號、聊天會員和 API 額度不能簡單當成同一回事；請以服務商當前後台、條款和價格為準。不要購買或使用來源不明的共享密鑰。

  1. 在瀏覽器打開 DeepSeek 官方開放平台 https://platform.deepseek.com/ ，自行完成註冊/登錄。
  2. 閲讀平台服務條款、私隱政策與價格，確認處理地區、請求是否保留以及是否用於訓練等條件適合你的用途。不確定就不要發送真實小票。
  3. 在平台 API Keys/密鑰管理入口創建專門給一塊記用的密鑰，並安全保存。若需要額度，是否付費由你自行決定；教程不要求充值，也不承諾免費額度。
  4. 官方接口説明：https://api-docs.deepseek.com/ 。服務後台名稱和模型列表可能變化，以官方説明及實際帳號權限為準。

泄露密鑰可能導致他人使用你的額度。不要把密鑰放進截圖、備註、提示詞或反饋；懷疑泄露立即到服務商撤銷並重新創建。

13. DeepSeek 示例：在一塊記逐格配置

  1. 打開“設定 → 智慧整理 → 外部大型語言模型 API”。首次配置直接填表；已有配置想保留時，先使用“建立設定”建立另一份再修改，不要覆蓋仍需使用的配置。
  2. “服務商預設”選 DeepSeek。“介面網址”核對為 https://api.deepseek.com/chat/completions 。切換預設不一定覆蓋你以前自定義的地址，請務必檢查域名。
  3. “API Key”粘貼你剛創建的密鑰，不添加引號、“Bearer ”前綴或額外空格。編輯已保存配置時留空可保留原密鑰；密碼框不顯示不代表沒保存。
  4. 點擊“自動取得模型”，從“已發現的模型”中選一個支持文字對話和 JSON 輸出、且帳號有權限的模型。模型名稱是服務商的精確 ID，不是你隨意起的名字。列表不支持時按其官方文件手動填。
  5. 先保留默認參數：思考模式“跟隨服務”、温度 0、輸出上限 8000、超時 120 秒，其他參數暫不改。温度控制結果變化程度；輸出上限不是固定費用，思考模式也可能增加耗時和費用。
  6. 點“測試連線”，成功後再點“儲存”。獲取模型列表和測試連接會帶密鑰向指定服務請求模型列表，但不會發送你的帳目或小票；成功只説明認證和列表接口可用，不保證整理接口、額度及所選模型一定可用。
  7. 回到設置檢查已有選中的配置。若配置多家服務，每次整理前都確認當前選中的那一份。

成功標誌：能保存配置並獲取列表；下一章用虛構文字測試實際整理。不要因為“連接成功”就馬上批量發送私人小票。

14. 外部整理第一次使用與報錯

  1. 準備一張只有“測試商店、日期、合計 10 元”的虛構小票圖片，不含姓名、手機號、卡號或他人信息，先在本機識別。
  2. 點擊“使用外部 API 整理”。確認彈窗中的服務域名、模型及思考設置，只有你同意後才會發送。批量操作的確認覆蓋所選批次，並非每張再彈一次。
  3. 請求包括識別出的文字塊、編號、條碼/二維碼候選內容及整理提示詞和模型參數；不附帶原圖。文字本身也可能含敏感信息，不願外發就取消並手動填寫。
  4. 等待結果後核對金額、幣種、日期、商户及分類，再確認保存。不要因模型回答流暢就省略核對。

401/403：檢查密鑰有效性和權限；404：核對接口與模型 ID；429：檢查限流/額度，不要反覆重試；超時：稍後再試或合理延長超時；返回被截斷：適當增加輸出上限、減少輸入或關閉不必要的思考。參數不兼容時恢復默認設置，查服務商文件。

取消應用中的任務不保證第三方立即停止處理或不計費。要停用後續請求，可移除對應配置；要使密鑰失效，還需在服務商後台撤銷。

15. 多張小票與後台限制

  1. 批量匯入最多 50 張圖片，應用會建立本地草稿隊列。
  2. 已配置外部模型時，可點“全部交由 LLM 核對”，閲讀批量外發提示再確認。批量會增加請求數量和可能產生的費用。
  3. “設定 → 智慧整理 → 批次整理並發數”決定同時處理幾張，默認 2，可設 1 至 4。限流或網絡不穩定時先調到 1。
  4. 完成後逐張打開草稿核對保存。失敗項目仍保留本地圖片與草稿，不會自動入帳。

儘量保持應用前台直到任務完成。iOS 只給有限後台時間；系統結束進程後，未完成任務不會自動恢復。重新進入草稿檢查，再決定重試哪些項目。

16. 匯率：參考值與實際付款的區別

  1. “設定 → 匯率設定”中，自動模式從歐洲中央銀行（ECB）獲取每日參考匯率並緩存；這是聯網功能，不上傳你的帳目。需要不聯網時改為手動模式。
  2. 手動模式填寫當前帳本需要的幣種對，核對換算方向。例如“1 美元等於多少人民幣”，不要把它填反。
  3. 保存記錄時會鎖定匯率。之後參考匯率更新，舊帳不會自行變化。銀行或支付平台實際扣款、手續費可能與參考值不同。
  4. 如確需更新歷史記錄，先看預覽再確認：自動模式處理最近 30 個自然日的適用記錄，手動模式處理全部適用歷史記錄，可能涉及多個未刪除帳本。週末等無報價日會使用此前可用的參考日。

ECB 原始信息經應用交叉換算；參考值不是實際成交承諾，也不是投資建議。來源：https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html 。使用條款：https://www.ecb.europa.eu/services/disclaimer/html/index.en.html 。

17. 匯出與恢復：先備份再換手機

  1. 先進入正確帳本，再到“設定 → 匯出資料”，按系統提示選擇保存位置並確認匯出。需要多本帳本時逐本處理。
  2. JSON 適合保留結構後導回一塊記，CSV 適合用電子表格查看。匯出文件是可讀文本，包含私人消費資料，不是加密文件，請保存在你能控制的位置。
  3. 當前匯出不打包照片文件，也不是整個應用的完整備份；草稿、連接密碼、模型密鑰等也不能靠該匯出完整恢復。原始小票、照片和所需憑據請單獨安全保留，不要匯出後立即卸載或清空原設備。
  4. 換機前，先在測試帳本里匯入驗證。進入目標帳本，點“設定 → 匯入資料”，選擇一塊記的 JSON/CSV，核對確認；目標帳本本位幣要一致。匯入是合併，不是把整個應用回滾到某一時刻。
  5. 只匯出部分記錄時，先篩選再多選、匯出，檢查範圍無誤。不要把私人帳目發給不相關的人。

成功標誌：新設備能查看金額、日期、分類及需要的附件，確認完整後再處理舊設備。不要把 WebDAV 同步當成獨立歷史備份。

18. 刪除、退出共享與安全求助

  1. 刪除記錄會先進入回收站，可在尚未永久清理時恢復；超過保留期（當前 30 天）的內容可能在清理時被永久刪除。共享帳目的刪除與恢復也會同步。
  2. 永久刪除共享單條記錄會嘗試清理遠端歷史操作和關聯照片；需聯網及寫入/刪除權限。同步未完成、服務商備份和成員已有副本不等於已經擦除。
  3. 斷開 WebDAV、刪除預設或關閉照片開關不會抹掉遠端資料。整本共享帳本尚無一鍵遠程清除功能。
  4. 若必須清理整本遠端資料：先與所有成員協商並完成必要備份，讓所有設備斷開；由存儲目錄所有者核實準確的帳本專用目錄後，在服務商處清理該目錄及其回收站/歷史版本，並撤銷相應憑據。不能確認目錄時先問服務商，絕不要刪除整個網盤或其他帳本。
  5. 需要移除成員時，不能僅換“我的名稱”或本機斷開。需在服務端撤銷該成員訪問權限/舊憑據，並評估建立新共享與新密鑰；已經下載的副本無法遠程收回。
