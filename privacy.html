1. 谁处理数据，以及本应用的边界

当前版本不要求注册一块记账号，没有已运营的一块记官方云端账本或订阅服务。本地数据由安装应用的设备保存；你主动选用的 WebDAV 服务与外部模型会分别处理相应请求。

经营者为薛正尧，客服与隐私请求统一通过 yikuaiji_feedback@163.com 接收。本应用不因你使用而取得账目或照片的数据权益；你保有依法享有的数据控制与选择权，他人原有权利不受影响。不能以“只在本地”“用户自带服务”或“数据归用户”替代经营者依法应履行的保护、告知与协助义务。

2. 本机保存哪些信息

设备中保存账本名称、本位币、分类、金额、商户、日期、备注、记录作者/成员标识、同步版本、草稿、识别文字、照片附件及偏好。用途是显示、编辑、统计、导出和在你选择时完成同步或整理。

API Key、WebDAV 凭据、共享密钥及预设使用系统安全存储。普通账目数据库、附件和导出文件不应被当作同等级的额外加密保险箱；请保护设备解锁方式，避免在共用设备存放敏感内容。系统备份或你选择的文件位置可能带来额外副本。

当前 iOS 版本启用了应用文档的系统文件共享，应用的文档目录可能在“文件”或电脑文件共享中可见，其中包含内部数据库和附件。不要向其他人共享整个应用目录，也不要在外部直接修改或删除内部文件。正式发布前将重新评估该存储与导出方案。

本客户端未接入广告追踪或开发者运营的行为分析服务。商店、操作系统及测试分发可能按其自身设置处理购买、安装或崩溃信息；不能由此宣称所有环境都“零数据收集”。

3. 相机、照片、文件与本地识别

拍照或扫码时使用相机；选取图片和导入/导出时调用系统选择器或文件访问能力，具体权限由平台决定。仅为所选功能使用相应内容，拒绝后仍可手动记账。可在设备系统设置撤销权限。

iOS/macOS 使用系统 Vision；Windows 使用设备端 OCR；Android 源码使用 ML Kit，实际发布前须另行核对其打包和初始化行为。可用时的 Apple 系统模型用于设备端整理。不提供因安装应用就默认把照片发给外部模型的功能。

图片可能含有 EXIF 等拍摄元数据；应用目前不承诺自动清除全部元数据。敏感照片在导入、共享前请自行检查，尤其不要包含无关人员、证件或金融账户信息。

4. WebDAV：加密内容、接收方与可见信息

只有配置共享并执行手动/快捷同步，或主动开启自动同步条件后，才向你指定的 WebDAV 地址传输共享操作。加密内容可能包括账本、分类、账目、成员信息及删除操作；草稿不是正式同步记录。

照片同步按设备和账本默认关闭。开启后，关联的小票/货品照片以共享密钥加密传输，远端缺图可跳过并之后重试。账目及照片使用 AES-256-GCM 加密；存储服务仍可见账号认证、IP 地址、请求时间、目录标识、文件大小等网络/存储信息。

获得共享密钥且有目录访问权限的成员能看到解密内容。普通邀请码含密钥；快速邀请还含加密保护的地址、账号及密码。复制会把内容放入系统剪贴板，二维码可被拍摄保存，某些系统还会同步剪贴板。请按凭据保护，使用后按需清空剪贴板。

保存位置、服务器日志、历史版本与保留时间由你所选服务及其账号设置决定；其运营者不是由本应用统一指定。选择服务前应核实其隐私保护措施，避免把私人网盘完整权限交给成员。

5. 外部模型：发出哪些文字、发给谁

每次单条请求或一次批量请求前，会显示你当前配置的域名与模型并征求确认。发送 OCR 文字块和编号、条码/二维码候选内容、整理提示词及模型参数；不会附带原始图片、设备文件路径或文字坐标。自定义提示词中你主动写入的内容也会发送。

API Key 通过认证请求头发送给你配置的服务。服务还会收到 IP 地址、请求时间、模型用量等网络信息。获取模型列表和测试连接只请求模型列表，不发送真实小票，但同样包含认证信息。

例如选择 DeepSeek 官方接口时，请求发往 api.deepseek.com；自定义域名时接收方是该域名对应的服务，不因下拉框选择 DeepSeek 就自动保证是其官方站点。示例不构成合作或保证。

识别文字可能包括姓名、联系方式、消费地点、账号或其他敏感内容；“只发文字”不等于匿名。应先核实服务的隐私政策、保存地区、保留期限、训练用途和删除渠道。不清楚这些条件时请使用本地功能，不要发送敏感信息。应用不能保证任意用户自配服务均已通过审查。

6. 其他联网、导出与诊断

自动汇率会访问欧洲中央银行（ECB）的公开汇率接口，默认自动模式可能在前台联网更新；它不发送你的账目金额、照片或成员名单，但数据来源服务会收到普通网络请求信息。可在汇率设置切换手动模式以停止该自动获取。

JSON/CSV 导出在所选位置生成可读文件，未经额外加密，不打包照片或完整应用配置。你选的网盘文件位置可能自动上传导出文件，不受 WebDAV 照片开关控制。

开发者模式默认关闭；主动开启后，最近的外部模型诊断会话保存在应用内存中，可能含识别文字、提示词、模型回应和报错。关闭后清空这些会话，不自动上传给开发者。复制诊断或主动提交反馈时请先删去敏感内容；隐去密钥不等于已匿名化消费信息。

如果你主动发送支持邮件，经营者会收到你的邮件地址、邮件内容及主动附带的文件，用于回复、排错和处理权利请求，不用于广告或训练。收件使用网易 163 邮箱，邮件服务商也会处理邮件传输、保存及相关网络信息。请仅提交必要的脱敏资料；不要发送完整账本、小票、密钥、密码或身份证件。仅在处理请求所必需期间保留，目的完成后删除或匿名化；因法定义务确需保留的，限制用途并在期限届满后处理。邮件服务商的备份及日志按其政策另行处理。

公开文档和支持网页使用 GitHub Pages 托管。网站不设置账号、付款、账本上传表单、开发者自建访问统计或广告追踪，也不读取应用内数据；访问时 GitHub 仍可能为安全与服务运行处理 IP 地址等访问日志，不能称为“完全不收集任何数据”。GitHub 隐私说明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement 。发送邮件或访问第三方链接会进入相应服务。

7. 保存多久、如何删除与撤回

本地正式记录通常保存至你删除或清理应用数据；草稿保留至确认、删除或清理。回收站当前保留期为 30 天，过期项目可能在应用执行清理时永久删除，不保证第 30 天即刻从每个设备和服务器删除。

单条共享账目的永久删除会尝试清理相关远端历史操作和照片，并保留最小删除标记用于阻止离线设备复活旧数据；操作需联网及相应权限。整本共享账本尚不支持一键远程清除。归档、断开、关闭照片同步和卸载都不是远端删除。

可随时停止自动/照片同步、断开 WebDAV、移除不需要的 WebDAV 预设或模型配置，在服务商处撤销密钥/应用密码，在系统设置撤回权限。停用不追溯撤销已完成的处理；已经开始的请求仍可能被第三方完成或计费。

要清除远端整本数据，应与成员协调、断开所有相关设备，核实准确目录后由目录所有者在服务商处删除内容及历史版本，并撤销访问。第三方日志、系统备份、导出文件和其他成员副本须分别处理。开发者无法承诺替你抹除所有独立主体保管的副本。

8. 跨地区处理与第三方保护

本地文件位于设备及用户选择的备份位置；WebDAV 和模型数据可能被处理在服务商公布的地区，未必与你或设备所在地区相同。HTTPS 和内容加密不是数据不跨境的保证。

涉及个人信息向其他主体提供、敏感个人信息或跨境处理时，须根据适用法律明确接收方、用途、保护措施和行使权利方式，并在要求时取得单独同意等，不以本说明的一般性告知替代这些要求。正式发布前需核实默认/示例服务及可配置服务范围的合规方案；本稿不保证任意自定义服务均适用。
