反饋前準備什麼

  1. 寫下設備型號、系統版本、應用版本或 TestFlight 構建號。
  2. 説明你做了什麼、期待什麼、實際發生什麼；能用虛構資料重現時優先使用虛構資料。
  3. 僅附帶已遮蓋私隱的報錯。不要發送 API Key、應用密碼、邀請碼、完整小票、帳本資料庫或身份證件。
  4. 涉及同步時，説明是否開啓照片同步、是否為不同設備、報錯發生在哪一步；不要把伺服器登錄信息發來。

測試期間也可以通過 TestFlight 提交反饋。我們不會要求你提供密碼或完整財務資料來獲取幫助。本郵箱不提供轉帳、投資或專業財税諮詢。

資料控制與恢復

你依法保有自己資料的權益，自主決定保存、匯出、刪除及是否分享；其他人的合法權益不受影響。請妥善保管設備、服務憑據和原始照片，定期驗證獨立備份。JSON/CSV 不打包照片，同步也不是獨立歷史備份。

當前沒有由開發者託管的官方帳本或恢復服務，我們通常不持有你的本地資料和解密憑據，不能承諾恢復丟失的資料。資料風險及法定責任詳見用户協議；“資料歸用户”不等於排除開發者依法應承擔的責任。

私隱請求請在郵件主題註明“一塊記私隱請求”，説明你需要查閲、更正、刪除或撤回的內容。僅核驗處理請求所需的最少信息，按適用法律要求處理。有關獨立服務商和其他成員持有的副本，會説明可行操作及能力邊界。
