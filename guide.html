1. 第一次使用：先不配云服务

一块记用来记录旅行、家庭、伴侣或小团队的支出。账本就像一本独立的记账簿；记录是一笔支出；草稿是尚未确认的记录。基本记账不需要注册一块记账号，也不需要 WebDAV 或 API Key。

  1. 打开底部“账本”，进入已有账本，或点“新建账本”。给账本取一个能认出的名字，例如“周末旅行”。
  2. 选择本位币，即统计总额统一使用的币种。例如平时看人民币总额就选 CNY。不要为了临时记录一笔美元支出而换整本账本的本位币。
  3. 进入账本，新增一笔虚构的“午餐 20 元”，检查日期、币种和分类，再点“确认保存”。
  4. 到“统计”检查结果。只有正式保存的记录才计入统计；筛选条件和当前账本也会影响结果。

成功标志：账本中看到记录，重新打开应用后仍能找到。到这里已经可以开始记账；后面的共享与外部整理都是可选功能。

2. 账本首页、切换与归档

  1. 底部“账本”是所有账本的首页，新建和进入账本都在这里完成。先进入你要使用的账本，再打开设置或统计，它们会作用于当前账本。
  2. 要整理不常用账本，打开账本卡片菜单，选择归档。归档只在本机隐藏首页入口，数据、附件和同步连接仍保留，也不会让其他成员的账本消失。
  3. 在账本首页右上角打开“已归档账本”，找到目标后恢复。最后一个未归档账本不能归档，以保留可用入口。

归档不是删除，也不是停止同步。想停用共享，请到对应账本的 WebDAV 页面断开连接。

3. 手动记账、退出和草稿

  1. 进入账本并新增记录，填写商户、金额、币种、日期、分类及需要的备注。
  2. 暂时不想保存，可正常返回或下滑关闭编辑页；已输入的内容会自动保存为草稿。不要用强制结束应用代替正常退出，系统终止、存储失败或设备故障时最后的改动仍可能丢失。
  3. 回到账本的草稿入口，继续编辑。草稿不进入正式统计，也不作为正式账目同步给其他设备。
  4. 核对后点击“确认保存”。编辑已有记录时也请确认保存后再检查结果。

成功标志：草稿中能恢复输入；确认保存后，正式记录出现。重要凭证仍请独立留存。

4. 拍照与导入小票：识别不等于入账

OCR 是“把照片里的字读出来”，不是替你核实消费。

  1. 新增记录时选择拍照或导入图片。首次使用相机/照片选择时，按系统提示授权；拒绝后仍可手动记账。以后可在系统设置中更改权限。
  2. 让小票平整、光线充足，尽量包含商户、日期和合计，避免反光、模糊或截掉金额。图片可能带有拍摄元数据，分享前请自行清理不想暴露的信息。
  3. 等设备端识别后，逐项核对：合计是不是实付金额、日期是否正确、币种有没有选错、退款或折扣是否误读。
  4. 如需外部模型辅助整理，先按 DeepSeek 章节配置，再主动选择“使用外部 API 整理”。不同设备的端侧能力不同，不能保证每台设备都有系统模型。
  5. 只有你点“确认保存”才入账。识别失败时可继续手填，不需要反复上传同一张照片。

5. 筛选、多选和统计

  1. 在“最近记录”旁打开筛选，可设置单日/日期范围、关键字及“付款人（记录人）”。条件会同时生效，日期范围包含起止两天。
  2. 保持筛选，点选择按钮或长按记录进入多选。“全选”及导出只针对当前筛选可见的结果；改条件后请重新核对所选项。
  3. 统计页可按日期和记录人查看分类、商户、日/月趋势；回收站记录和草稿不计入。

注意：当前“付款人（记录人）”主要依据记录作者标记，并非经过身份核验的实际付款人，也不是分账、转账或债务证明。旧记录可能显示“未标记记录人”。跨币种总额使用保存时锁定的本位币金额。

6. WebDAV 是什么，什么时候需要它

WebDAV 是让应用读写你指定的远程文件夹的一种方式。你可以选支持 WebDAV 的存储服务或自有服务器；不是所有网盘都支持。只在一台设备记账时可以完全跳过。

它和外部模型是两回事：WebDAV 存储并同步加密账目/可选照片；外部模型帮助整理文字。两者账号、密码和用途不同。

开始前准备四样东西：服务商给出的 WebDAV HTTPS 地址、WebDAV 用户名、专用应用密码，以及你在共享账本里的名称。服务本身可能收费；请自行阅读其价格、隐私政策、保存地区和访问权限。

请只与可信成员共享。加密不能阻止已经获准访问的成员复制、修改或删除内容；当前没有逐成员只读权限、踢人或自动换钥匙的功能。

7. WebDAV 准备：从服务商拿到正确资料

  1. 用浏览器登录你选择的服务商官方网站，查找“WebDAV”“第三方应用”“应用密码”或“安全设置”。不同服务入口不同，找不到时查其官方帮助，先确认服务支持 WebDAV。
  2. 启用 WebDAV（如果服务需要），按其指引创建专门给一块记使用的应用密码。应用密码类似单独配给应用的钥匙；不要默认使用网页登录密码，更不要填写短信验证码。
  3. 复制其文档指定的 WebDAV HTTPS 地址。它不是网页登录页，不是普通文件分享链接，也不是任意拼接的文件夹地址。
  4. 如服务支持，把权限限定到专用目录，例如 YiKuaiJi。地址是否需要附加子目录，以服务商说明为准；不确定时先在其官方客户端验证。不要授予整个私人网盘权限再把凭据发给别人。
  5. 保留正确的用户名和应用密码到你信任的密码管理器中。不要发给开发者，也不要截图到群聊。

格式示例：https://dav.example.com/your-folder/ 。这是示例地址，不能直接使用；请替换为自己的真实地址。必须使用有效 HTTPS，不能通过关闭证书校验来解决连接问题。

8. WebDAV 创建共享：第一台设备逐格填写

  1. 在“账本”进入要共享的账本。打开“设置 → 连接同步方式”，确认页面顶部账本名称正确，再选择“创建共享”。
  2. “WebDAV HTTPS 地址”：粘贴服务商提供的完整地址，检查有没有空格、漏掉 https:// 或误贴网页链接。
  3. “WebDAV 账号”：填写服务商指定的用户名，有的使用邮箱，有的使用独立用户名。
  4. “WebDAV 应用密码”：粘贴刚创建的应用密码。它不是一块记邀请码，也不是外部模型 API Key。
  5. “我的名称”：填其他成员能认出的称呼，例如“小林”；该名称会作为共享记录的成员信息，不必填真实姓名。
  6. 点击“创建并预览”。这一步会访问服务器验证权限，必要时创建应用目录，并读取远端状态；看到预览后，逐项检查上传/下载内容，再点击“确认同步”。取消预览不会撤销已保存的连接，请按需要另行断开。
  7. 页面显示“WebDAV 已连接”后，可选择“保存为 WebDAV 预设”并命名。以后新建账本时可复用地址与凭据，但仍需单独创建或加入共享。不要在公用设备保存预设。

成功标志：无连接错误，完成确认同步后出现同步结果。仅显示“已连接”还不等于另一台设备已拿到数据。

9. WebDAV 加入已有账本：第二台设备

  1. 创建者在已连接页面点“复制邀请码”，仅通过可信私密渠道发给你。普通邀请码含远程账本标识和解密钥匙，不含 WebDAV 账号或应用密码；它不是 TestFlight 兑换码，也不是商店购买凭证。
  2. 在第二台设备先创建空账本，选择与原账本相同的本位币。不要在有自己账目的账本上尝试合并加入。
  3. 进入该空账本，打开“设置 → 连接同步方式”，选择“加入已有”。填写能访问同一远端目录的 HTTPS 地址、账号、应用密码，以及你自己的“我的名称”。
  4. 粘贴完整“共享邀请码”，点击“加入并预览”，核对下载项后确认同步。
  5. 两台设备各新增一笔不含隐私的测试记录，分别同步，再在另一端同步并核对。先确认文字往返成功，再开启照片。

快速邀请是可选捷径：创建者点“生成快速邀请（含账号密码）”，设置 6 至 12 位数字口令；接收者点“导入快速邀请（含账号密码）”，粘贴文字或扫描二维码并输入口令，核对填入信息后再加入。数字口令应现场口头另行告知，不要和邀请文本发在同一条消息里。

快速邀请包含可解密的账号密码，数字口令的保护能力有限，不是一次性、可撤销或会自动过期的链接。不公开发布，也不转发给陌生人。服务允许时优先给成员发仅限专用目录的独立凭据。

10. WebDAV 同步确认、自动同步与照片

  1. 想每次先看清单，请到当前账本的 WebDAV 页面点“立即同步”，阅读上传、下载、删除和照片项目后再确认。
  2. 账本页右上角的快捷同步检查所有已连接账本，无冲突时直接完成，并非每次都给完整清单；同一字段冲突时需选择。图标旋转表示工作中，短暂变绿表示该次完成。
  3. 想自己掌控每次上传，保持“设置 → 自动同步”的各项关闭，并使用上述预览入口。开启进入前台、新增记录后或间隔同步，就是允许满足该条件时执行同步；它们只在应用前台工作，不保证后台持续同步。
  4. 需要共享照片时，在当前账本 WebDAV 页开启“同步小票照片”，阅读弹窗再确认。每台需要传/收照片的设备都应检查自己的开关。当前账本关联的小票及货品附件可能被同步，并不只针对之后新拍的图片。
  5. 未开启时只同步账目；另一位成员没有上传照片，或远端暂缺文件时，文字账目仍能同步。看到缺图提示不等于账目丢了；让持有原图的成员开启照片同步并补传，再在你的设备重试。

关闭照片同步只停止后续传输，不删除已上传照片。同步也不是独立备份：误删或错误修改可能传到所有设备。

11. WebDAV 连不上：按报错排查

  1. 401/403：先在服务商处确认账号、应用密码和专用目录权限；网页登录成功不代表 WebDAV 密码或权限正确。密码失效时重建专用密码，再修改连接。
  2. 404：连接时出现通常要核对完整地址及目录；同步完成后的“照片未上传/已跳过”提示只针对缺失附件，不要因此删除账本。
  3. 405/409：核对服务是否允许应用创建目录，以及路径是否是可用的 WebDAV 文件夹，不要反复新建共享或清空远端尝试修复。
  4. 429/配额不足：停止反复点击，等待限流恢复或到服务商检查容量、请求额度和文件大小限制。
  5. 超时/证书错误：检查网络、设备时间、服务器状态及 HTTPS 证书；不要关闭安全校验。解密失败时核对是否用了同一账本的邀请码，不要用强制上传来“试试看”。

“强制上传本地数据”是高风险修复工具，可能删除远端独有记录。新手不要用它排查网络问题。先导出并保留原始附件，与所有成员确认哪一端完整，再考虑该操作。

12. DeepSeek 示例：认识 API Key 与费用

外部模型是可选的文字整理助手，不是记账必需品。DeepSeek 只是配置示例，不表示一块记与其有合作、担保或绑定；也可以使用你信任的兼容服务。

API Key 是让应用访问你模型账号的密钥，类似应用专用密码。网页登录账号、聊天会员和 API 额度不能简单当成同一回事；请以服务商当前后台、条款和价格为准。不要购买或使用来源不明的共享密钥。

  1. 在浏览器打开 DeepSeek 官方开放平台 https://platform.deepseek.com/ ，自行完成注册/登录。
  2. 阅读平台服务条款、隐私政策与价格，确认处理地区、请求是否保留以及是否用于训练等条件适合你的用途。不确定就不要发送真实小票。
  3. 在平台 API Keys/密钥管理入口创建专门给一块记用的密钥，并安全保存。若需要额度，是否付费由你自行决定；教程不要求充值，也不承诺免费额度。
  4. 官方接口说明：https://api-docs.deepseek.com/ 。服务后台名称和模型列表可能变化，以官方说明及实际账号权限为准。

泄露密钥可能导致他人使用你的额度。不要把密钥放进截图、备注、提示词或反馈；怀疑泄露立即到服务商撤销并重新创建。

13. DeepSeek 示例：在一块记逐格配置

  1. 打开“设置 → 智能整理 → 外部大模型 API”。首次配置直接填表；已有配置想保留时，先使用“新建配置”建立另一份再修改，不要覆盖仍需使用的配置。
  2. “服务商预设”选 DeepSeek。“接口地址”核对为 https://api.deepseek.com/chat/completions 。切换预设不一定覆盖你以前自定义的地址，请务必检查域名。
  3. “API Key”粘贴你刚创建的密钥，不添加引号、“Bearer ”前缀或额外空格。编辑已保存配置时留空可保留原密钥；密码框不显示不代表没保存。
  4. 点击“自动获取模型”，从“已发现的模型”中选一个支持文字对话和 JSON 输出、且账号有权限的模型。模型名称是服务商的精确 ID，不是你随意起的名字。列表不支持时按其官方文档手动填。
  5. 先保留默认参数：思考模式“跟随服务”、温度 0、输出上限 8000、超时 120 秒，其他参数暂不改。温度控制结果变化程度；输出上限不是固定费用，思考模式也可能增加耗时和费用。
  6. 点“测试连接”，成功后再点“保存”。获取模型列表和测试连接会带密钥向指定服务请求模型列表，但不会发送你的账目或小票；成功只说明认证和列表接口可用，不保证整理接口、额度及所选模型一定可用。
  7. 回到设置检查已有选中的配置。若配置多家服务，每次整理前都确认当前选中的那一份。

成功标志：能保存配置并获取列表；下一章用虚构文字测试实际整理。不要因为“连接成功”就马上批量发送私人小票。

14. 外部整理第一次使用与报错

  1. 准备一张只有“测试商店、日期、合计 10 元”的虚构小票图片，不含姓名、手机号、卡号或他人信息，先在本机识别。
  2. 点击“使用外部 API 整理”。确认弹窗中的服务域名、模型及思考设置，只有你同意后才会发送。批量操作的确认覆盖所选批次，并非每张再弹一次。
  3. 请求包括识别出的文字块、编号、条码/二维码候选内容及整理提示词和模型参数；不附带原图。文字本身也可能含敏感信息，不愿外发就取消并手动填写。
  4. 等待结果后核对金额、币种、日期、商户及分类，再确认保存。不要因模型回答流畅就省略核对。

401/403：检查密钥有效性和权限；404：核对接口与模型 ID；429：检查限流/额度，不要反复重试；超时：稍后再试或合理延长超时；返回被截断：适当增加输出上限、减少输入或关闭不必要的思考。参数不兼容时恢复默认设置，查服务商文档。

取消应用中的任务不保证第三方立即停止处理或不计费。要停用后续请求，可移除对应配置；要使密钥失效，还需在服务商后台撤销。

15. 多张小票与后台限制

  1. 批量导入最多 50 张图片，应用会建立本地草稿队列。
  2. 已配置外部模型时，可点“全部交给 LLM 核对”，阅读批量外发提示再确认。批量会增加请求数量和可能产生的费用。
  3. “设置 → 智能整理 → 批量整理并发”决定同时处理几张，默认 2，可设 1 至 4。限流或网络不稳定时先调到 1。
  4. 完成后逐张打开草稿核对保存。失败项目仍保留本地图片与草稿，不会自动入账。

尽量保持应用前台直到任务完成。iOS 只给有限后台时间；系统结束进程后，未完成任务不会自动恢复。重新进入草稿检查，再决定重试哪些项目。

16. 汇率：参考值与实际付款的区别

  1. “设置 → 汇率设置”中，自动模式从欧洲中央银行（ECB）获取每日参考汇率并缓存；这是联网功能，不上传你的账目。需要不联网时改为手动模式。
  2. 手动模式填写当前账本需要的币种对，核对换算方向。例如“1 美元等于多少人民币”，不要把它填反。
  3. 保存记录时会锁定汇率。之后参考汇率更新，旧账不会自行变化。银行或支付平台实际扣款、手续费可能与参考值不同。
  4. 如确需更新历史记录，先看预览再确认：自动模式处理最近 30 个自然日的适用记录，手动模式处理全部适用历史记录，可能涉及多个未删除账本。周末等无报价日会使用此前可用的参考日。

ECB 原始信息经应用交叉换算；参考值不是实际成交承诺，也不是投资建议。来源：https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html 。使用条款：https://www.ecb.europa.eu/services/disclaimer/html/index.en.html 。

17. 导出与恢复：先备份再换手机

  1. 先进入正确账本，再到“设置 → 导出数据”，按系统提示选择保存位置并确认导出。需要多本账本时逐本处理。
  2. JSON 适合保留结构后导回一块记，CSV 适合用电子表格查看。导出文件是可读文本，包含私人消费数据，不是加密文件，请保存在你能控制的位置。
  3. 当前导出不打包照片文件，也不是整个应用的完整备份；草稿、连接密码、模型密钥等也不能靠该导出完整恢复。原始小票、照片和所需凭据请单独安全保留，不要导出后立即卸载或清空原设备。
  4. 换机前，先在测试账本里导入验证。进入目标账本，点“设置 → 导入数据”，选择一块记的 JSON/CSV，核对确认；目标账本本位币要一致。导入是合并，不是把整个应用回滚到某一时刻。
  5. 只导出部分记录时，先筛选再多选、导出，检查范围无误。不要把私人账目发给不相关的人。

成功标志：新设备能查看金额、日期、分类及需要的附件，确认完整后再处理旧设备。不要把 WebDAV 同步当成独立历史备份。

18. 删除、退出共享与安全求助

  1. 删除记录会先进入回收站，可在尚未永久清理时恢复；超过保留期（当前 30 天）的内容可能在清理时被永久删除。共享账目的删除与恢复也会同步。
  2. 永久删除共享单条记录会尝试清理远端历史操作和关联照片；需联网及写入/删除权限。同步未完成、服务商备份和成员已有副本不等于已经擦除。
  3. 断开 WebDAV、删除预设或关闭照片开关不会抹掉远端数据。整本共享账本尚无一键远程清除功能。
  4. 若必须清理整本远端数据：先与所有成员协商并完成必要备份，让所有设备断开；由存储目录所有者核实准确的账本专用目录后，在服务商处清理该目录及其回收站/历史版本，并撤销相应凭据。不能确认目录时先问服务商，绝不要删除整个网盘或其他账本。
  5. 需要移除成员时，不能仅换“我的名称”或本机断开。需在服务端撤销该成员访问权限/旧凭据，并评估建立新共享与新密钥；已经下载的副本无法远程收回。
